Search public Telegram

Channels, groups and bots. Type anything — no setup, no crawling. Results come from indexed t.me preview pages.

One-time setup (about five minutes, free)

  1. Go to Programmable Search Engine and create one.
  2. Under Sites to search, add t.me/* — nothing else.
  3. Turn Image search off and Search the entire web off.
  4. Copy the Search engine ID (the cx value).
  5. Paste it into CX near the bottom of this file, then reload.
